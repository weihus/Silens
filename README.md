# Silens (息壤) 📝

Silens 是一款基于 [Tauri](https://tauri.app/) 构建的极致极简、本地优先、零摩擦的沉浸式 Markdown 写作工具。应用秉承“启动即写、数据主权、拒绝干扰”的设计原则，为您提供“一期一会”般的专注写作体验。

## ✨ 项目简介

Silens 致力于提供无干扰的沉浸式写作空间。得益于 Tauri 的底层架构，Silens 具有极低的内存占用和极快的启动速度。笔记全部以纯文本 `.md` 格式保存在本地机器的 `Documents/Silens_Notes` 目录下，不含任何私有元数据，彻底保障您的数据隐私，且不依赖任何云端服务。

## 🛣️ 路线图与进度 (Roadmap & Progress)

- [x] **沉浸式编辑与静默保存**：无标题起笔，键盘输入时 UI 褪去，停止输入 1500ms 后静默保存至 `YYYY-MM-DD.md`。
- [x] **意识流幽灵标签 (Ghost Tag) 与块级解析**：无颜色块包裹束缚，摒弃单行截断。通过纯文本 `#标签` 自由书写，允许单回车自由换行，**双回车自动切分**并归档整个内容块，极致还原无摩擦的 Markdown 输入流。
- [x] **背景白噪音引擎**：细雨 (Rain)、篝火 (Fire)、深夜 (Night) 三款环境音，去除社会化底噪（如咖啡馆），保留绝对的独处静谧。
- [x] **物理级打字机与智能休眠**：引入弹簧阻尼算法，打字时纸张如丝绸般平滑上推锁定在视区 35%；鼠标滚轮或方向键浏览时瞬间休眠，为修改让路。
- [x] **图钉双栏模式 (Pin Mode)**：时间轴侧边栏支持一键锁定，主编辑区丝滑流体让位。
- [x] **暗影索引与状态翻转**：隐藏 SQLite 索引加持，侧边栏支持原地水雾转场，一键翻转为全局标签云。
- [x] **Spotlight 级全局穿梭**：悬浮玻璃态命令面板 (Cmd+K)，支持富上下文“卡片透视”，回车精准穿越并触发“幽灵高亮”。
- [x] **静默安全备份**：关闭应用或每隔 6 小时自动生成数据快照，智能保留最近 10 份。
- [x] **双向链接 (Bidirectional Link)**：输入 `[[` 触发自动补全，支持前缀、子串、模糊三种匹配策略，从所有历史笔记中精准选取关联文档，点击链接瞬间穿梭。
- [ ] **云端 AI 管家 (Pro)**：后台静默语义拆解与结构化。
- [x] **云盘工作区转移**：安全迁移工作区至 iCloud/OneDrive/Dropbox，享受云同步的便利，同时兼顾本地数据快照双重保险。

## � 技术栈

本项目采用了现代化的前后端分离架构，通过 Tauri IPC 进行高效通信：

- **前端 (表现层)**: React 19 + TypeScript + Vite + Tailwind CSS
  - **编辑器**: TipTap (ProseMirror) 实现无缝的“所见即所得” Markdown 体验。
    - **状态与交互**: React 原生状态管理，Framer Motion 动画，Spotlight 风格全局命令面板，及基于 html2pdf.js/html-to-image 的多格式导出。
- **后端 (系统层)**: Rust + Tauri Core
  - `std::fs` / `walkdir`: 负责底层高性能的本地文件系统遍历与 I/O。
  - `serde` / `serde_json`: 负责 Rust 结构体与前端 JSON 数据的无缝序列化/反序列化。
  - `rusqlite` (SQLite): 构建高性能的暗影索引引擎，在坚守 `.md` 数据主权的前提下实现毫秒级结构化复杂查询。

## 🚀 主要功能模块 (Core Features)

### 1. 纯粹的沉浸画布 (The Zen Canvas)
- **无标题、无摩擦起笔**: 抛弃传统的“新建-命名-写作”流程。打开应用，光标即刻在属于“今天”的空白纸张上闪烁，一切以时间为天然坐标。
- **打字锁定 (Typing Lock) 与世界退场**: 极致克制的界面。一旦敲击键盘，不仅鼠标指针强制隐形，顶部 Logo、底部字数统计与设置入口也将同步在 300ms 内平滑褪去，达成“开始写作 → 世界退场”的绝对静默。停笔 1000ms 后，世界才会重新平滑显现。
- **物理级打字机与智能休眠 (Spring Typewriter & Intent-Aware)**: 放弃生硬的居中滚动，引入物理弹簧阻尼算法。打字时纸张带着真实重量感平滑上推，将视线永远锁定在屏幕 35% 的黄金比例处。当使用鼠标或方向键修改旧文时，打字机会智能休眠，绝不抢夺视线控制权。
- **沉浸式隐匿与渐变遮罩 (Zen Fade & Vignette)**: 底部自带随日夜主题无缝切换的渐变遮罩。敲击键盘或滚动鼠标时，底部的字数统计、番茄钟等元素瞬间隐匿；停笔 1秒后，又如水面浮字般静静浮现。
- **氛围设置面板 (Atmosphere Panel)**: 通过 `Cmd/Ctrl + Shift + M` 唤出的设置面板采用极其克制的幽灵态无边框设计，摒弃传统表单分类（无 `THEME` / `SOUND` / `VOLUME` / `FOCUS` 标题与分隔线），仅以微弱背景色块与透明度变化指示“未激活 / 悬停 / 激活”三态。音量滑块轨道纤细、拇指低调，导出降级为底部无边框幽灵按钮、悬停才浮现背景。整体视觉降噪确保即便在调整参数时，也能维持绝对的沉浸感与视觉秩序。

### 2. 意识流与自动归档 (Stream of Consciousness & Auto-Routing)
- **无感知 Markdown (Invisible Markdown)**: 废弃传统 H1-H6 标题层级等打断思绪的语法，仅保留加粗斜体。结合 620px 黄金阅读宽度，打造无边界的时间瀑布流。单次回车紧密相连，**双次回车产生极其舒适的 48px~64px 呼吸留白**，完美契合底层的“新内容块”直觉。
- **“一纸写万物”的块级标签**: 无需频繁切换页面。在同一张纸上，你可以随手打上 `#待办` 记录工作，下一行打上 `#电影` 写下影评。系统底层会自动将不同标签的内容切分为独立的区块。
- **静默文件系统 (The Silent Disk)**: 输入停止后 1500ms 静默写入本地，每天自动生成 `YYYY-MM-DD.md` 进行存储。你只需“倾倒”，系统负责“保管”。
- **时间瀑布流回顾**: 侧边栏抛弃了复杂的树状文件夹体系，采用最符合人类直觉的“按月/日的时间线瀑布流”，配合平滑展开，优雅回顾过往记录。
- **侧边栏状态翻转 (State Swap)**: 点击侧边栏顶部的 `#` 标识，时间轴将如水雾般消散，原地翻转为“全局标签云总目录”。点击标签瞬间切换为平行时间线，搭配动态高度虚拟滚动与可拖拽时光刻度盘，体验惊艳。
- **图钉双栏模式 (Pin Mode)**: 在回顾整理时，点击侧边栏的“图钉”，主画布会如流体般向右丝滑推挤让位，化身极致高效的双栏比对工作台，彻底告别“鼠标移出自动关闭”的焦虑。
- **全知之眼与幽灵穿梭 (Spotlight & Ghost Highlight)**: `Cmd+K` 唤出极致轻盈的玻璃态命令面板，独创“卡片透视 (Context Preview)”双栏预览，在海量历史中秒级检索。回车后瞬间穿越至旧日画布，目标内容伴随 1.5 秒的“幽灵高亮”平滑浮现，思绪毫无断层。
- **全自动备份堡垒**: 后端运行极低开销的常驻守护线程，退出应用或每 6 小时自动快照整个工作区至 `Silens_Backups`，并智能修剪仅保留最近 10 份，提供大厂级的数据安全感。

- **云盘工作区转移 (Cloud Workspace Transfer)**: 允许用户将 Silens 的主工作区安全地转移至本地的 iCloud Drive、OneDrive 或 Dropbox 文件夹。系统将自动适应云盘同步机制，实现跨设备无感接续写作。所有数据快照备份将强制保留于本地 `Documents/Silens_Backups`，即便云盘失效或离线，本地数据安全仍有双重保障。

### 3. 精神避难所 (Personal Sanctuary)
- **内置白噪音引擎**: 集成高质量 Web Audio 引擎，提供极其克制的三款环境音：细雨 (Rain)、篝火 (Fire)、深夜 (Night)，一键隔绝外界喧嚣。
- **独裁美学排版 (Dictatorial Typography)**: 不提供任何字体和排版设置。系统强制调用 macOS / Windows 最顶级的原生无衬线字体栈，焊死 `19px` 字号、`1.9` 行高、`620px` 行宽，并使用低对比度的深灰色 (`#2f3441`)，彻底接管您的排版焦虑。
- **优雅导出**: 支持导出为 Markdown、纯文本、PNG/JPG 图片，保留完整排版样式。

### 4. 高阶：隐形管家 (AI Invisible Manager) [🔥 Pro 特性预览]
- **免费版基本盘**: 依靠底层高能的 Rust 正则算法，毫秒级在本地聚合你的 `#标签` 块，生成结构化的瀑布流回顾。
- **AI 语义拆解 (规划中)**: 针对无标签的“纯意识流”文本，云端 AI 管家将在后台静默将其拆解为待办、日记、读书笔记等不同实体，并支持通过“AI 灵魂对话”唤醒你的第二大脑。

## ⌨️ 快捷键指南 (Keyboard Shortcuts)

为了保证极致的沉浸感与无摩擦操作，Silens 移除了大量传统按钮，转而提供极其高效的全局快捷键（完美适配 macOS 与 Windows/Linux 键位）：

- **全局搜索穿梭 (Spotlight)**: `Cmd / Ctrl` + `K`
- **呼出 / 收起时间轴 (Timeline)**: `Cmd / Ctrl` + `L`
- **开启 / 关闭一期一会 (Focus Mode)**: `Cmd / Ctrl` + `Shift` + `F`
- **打开 / 关闭氛围设置 (Atmosphere)**: `Cmd / Ctrl` + `Shift` + `M`
- **撤销 (Undo)**: `Cmd / Ctrl` + `Z`
- **重做 (Redo)**: `Cmd / Ctrl` + `Y` 或 `Shift` + `Cmd / Ctrl` + `Z`

## 💻 开发与构建

### 环境准备

在开始之前，请确保您的开发环境已安装以下依赖：
- Node.js (推荐 LTS 版本)
- Rust (通过 `rustup` 安装)
- Tauri 开发环境依赖 (视您的操作系统而定：Windows 需 C++ Build Tools，macOS 需 Xcode，Linux 需 webkit2gtk 等)

### 安装依赖

克隆项目到本地后，在项目根目录下安装前端依赖：

```bash
npm install
```

### 本地开发 (Development)

你可以选择仅启动前端环境，或启动完整的 Tauri 桌面端环境：

**仅启动前端 (Web 模式)**:
```bash
npm run dev
```

**启动完整桌面端 (Tauri 模式)**:

```bash
npx tauri dev
```
*首次运行由于需要编译 Rust 依赖，可能会花费一些时间，请耐心等待。后续编译会利用缓存，速度大幅提升。*

### 打包构建 (Build)

当您准备发布应用时，运行以下命令。Tauri 会自动构建前端产物，并将其与 Rust 后端编译为各平台原生的可执行文件（如 `.exe`, `.app`, `.dmg`, `.deb`）：

```bash
npm run tauri build
```
构建产物将输出在 `src-tauri/target/release/bundle/` 目录下。
