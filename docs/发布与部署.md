# 发布与部署

## 签名与发布

发布前需将与 `src-tauri/tauri.conf.json` 公钥配对的私钥配置到 GitHub Actions Secret `TAURI_SIGNING_PRIVATE_KEY`；如有密码，再设置 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。私钥应安全备份，禁止提交仓库。发布 tag、`package.json`、`Cargo.toml` 和 Tauri 版本必须一致，例如 `v1.2.0` 对应 `1.2.0`。流水线收齐三平台签名包后生成 `latest.json` 并一起发布。

macOS 发布需要 Developer ID Application 证书和 Apple 公证凭据。将 `.p12` 文件的 Base64 内容配置为 `APPLE_CERTIFICATE`，导出密码配置为 `APPLE_CERTIFICATE_PASSWORD`，完整签名身份配置为 `APPLE_SIGNING_IDENTITY`。公证还需 `APPLE_ID`、App 专用密码 `APPLE_PASSWORD` 和 `APPLE_TEAM_ID`。这些值应保存在 GitHub Actions Secrets 中。

发布任务会检查 DMG 和应用内更新归档中的应用签名与公证状态。发布后，在 Gatekeeper 开启的 Apple Silicon Mac 上重新下载安装包并试启动。

## 产品介绍页

在仓库根目录运行 `python3 -m http.server 4174 --directory website`，打开 `http://localhost:4174` 预览介绍页。

GitHub 仓库的 Settings → Pages → Source 选择 **GitHub Actions** 后，推送 `website/` 改动会由 `website.yml` 部署。发布地址见该工作流的部署结果。
