# Silens · 息壤：产品与实现蓝图

本文描述当前仓库的设计共识。操作说明见 [使用手册](../MANUAL.md)，开发版与已发布版本的差异见 [更新记录](../CHANGELOG.md)。

## 1. 核心理念

Silens 是本地优先、打开即写的 Markdown 书写空间。界面在输入时退后，在需要回顾时提供清楚的线索，文字由用户长期拥有。

一个内容库容纳两种书写状态：随记接住当下，篇目支持围绕一个问题持续展开。默认进入今天的随记，用户需要独立成篇时再主动新建。

视觉沿用温暖纸面、柔和墨色、灰绿色辅助控件与适量留白，遵循系统减少动态效果偏好。

## 2. 书写边界

### 随记

- 默认文件为 `YYYY-MM-DD.md`，承载当天的多段记录。
- 书写前无需填写标题；已有日期后缀文件继续按随记读取。
- 回顾时按内容块与标签展示，点击片段回到真实来源文件。

### 篇目

- 从回顾侧栏“＋”或命令面板“新建篇目”进入。
- 标题与正文构成一篇，独占一个 Markdown 文件，允许先写正文、稍后补题。
- 文件身份稳定；修改显示标题不自动重命名文件，已有链接保持有效。
- 回顾时展示标题与摘要，标签命中后仍打开全文。

### 一期一会

随记与篇目共用句子专注、打字机滚动、专注计时和环境音。进入或退出专注不改变文档身份，结束时停留在当前内容。

## 3. 回顾与召回

- **时间**：按创作日期共同浏览随记片段与篇目，默认本月，提供周／月／年切换、相邻周期翻页、日期标题直达和返回当前周期；周一至周日构成完整一周，月与年使用完整自然周期。
- **分层回顾**：周按天展示片段，月压缩每日预览并支持展开，年按月份组织并预览部分内容；从年进入月后可返回原年，同一年内翻阅月份时保留返回入口。
- **标签**：跨日期回顾同一主题下的两类内容，篇目按文件去重。
- **继续写作**：独立于时间、标签两个主要视角，打开篇目列表，默认按最近修改排列，可切换创作时间排序；条目只显示当前排序所需的日期，完整时间按需查看。
- **交叉筛选**：周期或自定义范围在时间、标签和篇目视图间保留；切换周期更新当前标签结果，“日期”菜单与范围旁的清除按钮可返回全部时间。
- **浏览状态**：同次运行中保留周期、展开状态和各视图的滚动位置；关闭重开或年到月往返后恢复，加载时的滚动归零与过期请求不覆盖当前选择。
- **搜索**：同时匹配标题和正文，有结果时提供上下文预览；空查询提供昨天、本周、本月、本年和自定义范围快捷入口，点击结果才切换写作文档。
- **链接**：Wiki 链接绑定文件身份，显示名称可使用别名；反链展示来源标题与引用片段。

浏览与筛选保留正在编辑的文档。导航以真实文件名为身份，日期用于组织和筛选，不能代替文件身份。

### 时光拾遗

- 在当前画布之上展开信纸长卷，打开前完成待保存内容；收起时恢复当前文档的选区与滚动，点击原文卡片才进行文档导航。
- 本地确定性聚合组织为光阴刻度、万象与深潜、慢火长卷和吉光片羽；同一范围、视角与抽样种子得到相同结果，“换一束光”更换精选片段。
- 侧栏仅在当前结果成功且有记录时显示展卷入口。长卷提供日期与视角筛选，快捷标签取当前范围内有记录的前五项，空状态根据全范围结果引导查看全部或回到当前正文。
- 汇总与实体特征保存在可重建的本地 SQLite 索引中，依据 Markdown 与创作时间登记派生。展示使用叙述和原文片段，保留无标签内容。
- PNG / JPG 导出捕获完整信笺与印章，排除操作控件、空态引导和界面额外留白；进入专注模式收起长卷。

### 可选 AI 按语

本地长卷独立于 AI 工作。AI 默认停用，支持本机回环接口或 HTTPS 云端接口；每次查看脱敏载荷并明确确认后才发送单次请求，失败不自动重试。完整用户 JSON 限于 1500 个 Unicode 字符，预览与发送一致，固定写作指令另行发送。

云端密钥使用系统凭据库，普通配置保存在应用本地目录。生成内容只用于当前长卷和图片导出，关闭长卷后清除；正文、创作时间登记与备份格式保持原有约定。

## 4. 时间与文件

创作时间回答“从什么时候开始”，最后修改时间回答“最近推进了什么”。两者自动记录，编辑和索引重建保持创作时间不变。

```text
Documents/Silens_Notes/
  2026-11-03.md
  article-<uuid>.md
  .silens-created.json
```

- Markdown 是正文的真实来源；篇目标题保存为首个标准一级标题，与正文一起读写。
- `.silens-created.json` 独立登记固定的创作时间，随笔记库备份和迁移；正文不嵌入私有索引元数据。
- 随记沿用有效日期文件名的日期；旧篇目首次按可取得的原文件创建与修改时间中较早的一项补录。
- 最后修改时间来自文件修改时间，复制和恢复时保留；迁移到已有工作区时保留目标原有笔记的时间。
- SQLite 位于应用本地数据目录，是可重建的查询索引，不能代替正文或创作时间登记。

## 5. 保存与保护

- 标题与正文属于同一文档会话，共用 1500ms 防抖和串行写入队列；仅有标题时也可保存。
- 切换文档前保存，失败时保留当前页与文字；尚无标题和正文的新页面不创建空文件。
- 写入比较上次磁盘基线，检测外部修改或删除时拒绝覆盖，提供保留副本、重新读取和导出入口。
- 正常关闭前完成保存与快照；快照经复制校验后发布，保留最近 10 份。
- 工作区迁移先检查冲突，复制并校验后切换，原文件保留；创作时间登记按笔记合并。
- 恢复前保存当前工作区快照，再恢复所选快照并重建索引。
- Markdown、纯文本、PNG 和 JPG 导出均包含篇目的标题与正文。

## 6. 实现与验证

- 外壳：Tauri v2 / Rust；文件操作使用 `std::fs` 与 `walkdir`，查询索引使用 SQLite。
- 前端：React 19 / TypeScript / Vite / Tailwind CSS，TipTap / ProseMirror 与 tiptap-markdown 提供编辑与序列化。
- 文档会话、保存、焦点、滚动和面板互斥应维持明确边界，复用同一编辑器支持两种内容。
- 验证覆盖标题与正文合并保存、冲突保留、文件身份、创作时间稳定、时间与标签交叉筛选，以及备份、恢复和迁移的时间保留。
- 界面变更检查普通随记与篇目两条路径、窄窗口、主题及“一期一会”，并观察实际页面。
- 性能目标沿用空闲内存低于 100MB、输入延迟低于 16ms，具体结果以实测为准。

后续入口以实际书写中的摩擦为依据，保持打开即写和自主展开的体验。
